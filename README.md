\# CloudBites — Azure Observability Stack



\## About the Project

CloudBites is a cloud-kitchen and food-delivery application developed as part of a Microsoft Azure hackathon. The project combines order management with cloud-based application monitoring to demonstrate how operational data and system metrics can support reliable application operations.



\## Problem Statement

\*\*Azure Managed Grafana and Prometheus Observability Stack\*\*



Modern applications need effective monitoring to understand application performance, track operational metrics, and identify potential issues. This project explores how Azure's managed observability services can collect, monitor, and visualize application metrics in a centralized environment.



\## Solution

CloudBites combines a food-ordering workflow with an observability stack using:

\- \*\*Frontend:\*\* React, Vite, and TypeScript

\- \*\*Backend:\*\* Node.js and Express

\- \*\*Metrics:\*\* Prometheus client for exposing application metrics

\- \*\*Monitoring:\*\* Azure Monitor Managed Service for Prometheus

\- \*\*Visualization:\*\* Azure Managed Grafana



\## Key Features

\- Food-ordering and order-management interface

\- Backend API for processing orders

\- Application metrics exposed through a Prometheus-compatible endpoint

\- Azure-based metrics monitoring and Grafana dashboard visualization

\- Operational and system-health monitoring



\## Technology Stack

React · TypeScript · Node.js · Express · Prometheus · Azure Monitor · Azure Managed Grafana
